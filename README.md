# ALT дүкені

ALT студенттеріне арналған қазақ тіліндегі онлайн дүкеннің оқу жобасы.

**Жоба авторы: Турсунбай Инкар.**

![Сайттың басты беті](docs/site-preview.png)

## Мүмкіндіктері

- Үш санаттағы сегіз үлгі тауар.
- Атауы, санаты және сипаттамасы бойынша іздеу.
- Бағамен өсу және кему ретімен сұрыптау.
- Киім өлшемін таңдау: S, M, L, XL.
- Себетке қосу, санын өзгерту және тауарды өшіру.
- Жалпы соманы автоматты есептеу.
- Себетті браузердің localStorage қоймасында сақтау.
- Аты мен тобын енгізіп, демо тапсырыс жасау.
- Телефон экранына бейімделген интерфейс.

## Технологиялар

HTML, CSS және JavaScript. Сыртқы JavaScript кітапханалары мен құрастыру құралдары қажет емес.

## Іске қосу

Репозиторийді жүктеп, мұрағатты ашыңыз. `index.html` файлын браузерде ашыңыз.

Жергілікті HTTP серверімен ашу үшін жоба қалтасында мына команданы орындауға болады:

```bash
python3 -m http.server 8000
```

Содан кейін браузерде `http://localhost:8000` мекенжайын ашыңыз.

## Құрылымы

```text
index.html       Беттің бөлімдері мен формалары
styles.css       Безендіру және бейімделу ережелері
app.js           Каталог, іздеу, себет және тапсырыс логикасы
assets/          Тауар суреттері және сайт белгішесі
docs/            Есеп, презентация және экран көрінісі
```

## Оқу нұсқасының шарттары

Тауарлар мен бағалар үлгі ретінде берілген. Нақты төлем алынбайды және тапсырыс дүкенге жіберілмейді. Себет пен соңғы демо тапсырыс тек сол браузерде сақталады. Бұл нұсқада серверлік бөлік, тіркелу және нақты тауар қоры жоқ.

Тауар суреттері жобаға берілген бастапқы презентациядан алынды.
